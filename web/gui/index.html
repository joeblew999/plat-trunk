User Guide

Getting Started

A parametric 3D modeler running entirely in your browser using WebGPU. Create primitives, combine them with boolean operations, and export your designs as JSON.

Adding Primitives

Set the Size parameter, then click a shape button. Each new primitive is auto-offset so objects partially overlap (ready for booleans).

  • Cube — box with the given edge length
  • Sphere — sphere with the given radius
  • Cylinder — radius = size/2, height = size
  • Torus — major radius = size, tube radius = size * 0.3

Transforms

Select an object by its index, set dx/dy/dz values, and click Move Selected.

Boolean Operations

Combine two overlapping objects using CSG:

  • Union — merge A and B together
  • Subtract — cut B from A
  • Intersect — keep only the overlap

Enter object indices for A and B, then click the operation. The originals are replaced with the result.

Scene Management

Objects are listed by index. The selected object is marked with *.

  • Delete Sel. — remove the selected object
  • Clear All — remove everything

Save / Load

Designs save as JSON with full B-Rep data (no tessellation loss).

  • Save JSON — downloads a .json file
  • Load JSON — restores a saved scene
