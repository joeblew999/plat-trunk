User Guide

A parametric 3D modeler running entirely in your browser using WebGPU.

1. Getting Started

When the app loads you see a default cube in a 3D viewport. Drag to rotate, scroll to zoom.

2. Creating Shapes

Set the Size parameter, then click a shape button. Each new shape is automatically offset so objects partially overlap — ready for boolean operations.

  • Cube — box with the given edge length
  • Sphere — sphere with the given radius
  • Cylinder — radius = size/2, height = size
  • Torus — major radius = size, tube radius = size × 0.3

3. Moving Objects

Select an object by its index, enter dx/dy/dz values, and click Move Selected. Objects move relative to their current position.

4. Boolean Operations

Combine overlapping objects using CSG (Constructive Solid Geometry):

  • Union — merge A and B into one solid
  • Subtract — cut B out of A
  • Intersect — keep only the overlap

Enter object indices for A and B, then click the operation. The originals are replaced with the result.

5. Scene Management

Objects are listed by index. The selected object is marked with *.

  • Delete Sel. — remove the selected object
  • Clear All — remove everything and start fresh

6. Save / Load

Designs save as JSON with full B-Rep data (no tessellation loss). You can reload them later without any quality degradation.

  • Save JSON — downloads a .json file
  • Load JSON — restores a saved scene

Known Issues

  • Sphere/Torus booleans fail — Boolean operations only work reliably with cubes and cylinders. Sphere and torus booleans crash due to NURBS surface intersection limitations in the upstream truck-shapeops library.
  • No click-to-select — Objects are selected by index number, not by clicking on them in the viewport.
  • Object size changes after translate — Moving an object may slightly change its rendered size due to bounding box renormalization. This is a rendering artifact, the B-Rep geometry is unchanged.
  • Large translations go off screen — The camera doesn't follow translated objects. Keep dx/dy/dz values small (0.1 to 5.0) to stay in view.
  • No rotate/scale — Only translate is currently supported.
  • No undo — All operations are permanent. Save your scene before destructive operations.
